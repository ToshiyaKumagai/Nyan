1. 案件の入力の所在を受け取る：プロジェクトページ（StandUp）URL、タスク表、論点シート、IT基盤の進捗、Slack チャンネル
2. `skills/progress/SKILL.md` に沿って `--dry-run`。18節目の表を出し、人が全部読む
3. 評価の規約（`progress` の表）を1回目の結果で直す。直すのは `skills/progress/SKILL.md` だけ。理由を `CHANGELOG.md` に1行
4. 書き込み → フロントのレビュー（ページ「レビュー」節かコメント）→ `--review` で反映、を1周
5. `notify` の下書きを見て、初回投稿
6. `evals/` にケースを置く（`claude plugin eval`）

## 守ること

- 判断できる情報が無ければ判断しない。「事実確認」に置く
- 根拠 URL の無い○×を付けない。無いことを × にしない
- 本体はページ、プロパティは要約。置き換える節と追記のみの節を守る
- 人の書き込みを上書きしない。レビューを受けて直すのは nyan
- 案件固有の値と Slack の投稿先をリポジトリに書かない
- 標準の写しを手で直さない。直すなら donyu-standard に PR
