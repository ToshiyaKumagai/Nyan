# Slack に投稿する（ツール層）

## 手順

1. **投稿先を確定する。** `#name` なら `slack_search_channels` で ID を取る（同名が複数あれば利用者に選んでもらう）。URL ならそのまま。スレッド指定があれば親メッセージの ts を取る
2. **下書きを見せる。** `slack_send_message_draft` で、投稿先と本文をそのまま提示する。ここで止まり、承認を待つ
3. **投稿する。** 承認されたら `slack_send_message`（スレッドなら `thread_ts` を付ける）。差し戻されたら本文を受け取り直して 2 へ
4. **URL を返す。** 投稿のパーマリンクを返す（呼び出し側が Notion に控える）

## 作法

- メンションは利用者が指定した人だけ。`@channel`／`@here` は使わない
- 1回の呼び出しで1チャンネル。同報しない
- 長文はスレッドに分ける（親に3つの塊の要点、スレッドに詳細）
- 投稿の本文を勝手に短くしたり言い換えたりしない（中身は `notify` の責任）

## しないこと

- 承認前に投稿する／予約投稿を勝手に使う
- 文面の評価や言い換え
