# P2-1. 導入開始の宣言と推進体制の周知

| 欄 | 内容 |
| --- | --- |
| なぜこのマイルストーンがあるのか | Henry の導入開始を院内に宣言し、その進め方と推進体制（推進リーダー・各部署の推進委員）を院内に周知するため。あわせて、電子カルテ導入の先に何を目指すのかというゴールを定め、導入期間中の道しるべとなる目標について共通認識を持つ起点にする。 |
| 現行の呼称 | 全体キックオフ |
| 計画日 | N-4月2週 |

| 操作習熟 | — | — |

| システム連携 | 病院 | 連携先を確認する担当が、相手方への確認に着手している |
| 契約・事務 | — | — |
