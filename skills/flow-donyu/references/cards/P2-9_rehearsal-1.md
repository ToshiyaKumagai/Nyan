# P2-9. フローと実業務の整合性の初回検証

| 欄 | 内容 |
| --- | --- |
| なぜこのマイルストーンがあるのか | 部門横断の運用について、構築した運用の仮説を検証し、運用フローと実務のずれを、稼働前に推進担当者自身の操作で洗い出すため。 |
| 現行の呼称 | 第1回リハーサル |
| 計画日 | N-2月2週 |
