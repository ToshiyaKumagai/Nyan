# P3-3. 病院主導による稼働前の最終予行

| 欄 | 内容 |
| --- | --- |
| なぜこのマイルストーンがあるのか | この時点までに決めた運用を、病院側が企画・進行する検証の場で、本番の設定と機器を使って通し、稼働日から回せることを確かめるため。導入後に運用構築と Henry の運営を病院側が主体的に行っていけるかを、病院側自身が実感する場でもある。 |
| 現行の呼称 | 第2回リハーサル |
| 計画日 | N-1月2週 |

## 理想状態

| カテゴリ | 主語 | 理想状態 |
| --- | --- | --- |
| 運用構築 | 病院 | 病院側が、リハーサルで見つかったずれを自分で運用フローに反映している |
| 運用構築 | 病院 | 病院側が、リハーサルの振り返りの観点を自分で立て、振り返りで挙がったことを記録して自部署に展開している |
| 電子カルテ設定 | 病院 | 病院側の担い手が、リハーサルで見つかった設定の修正を自分で行っている |
| 操作習熟 | 病院 | 推進担当者が、現場から聞かれた操作の質問に自分で答え、ヘンリーへの問い合わせが減っている |
| 操作習熟 | 双方 | 病院とヘンリーが、習熟の浅い職員・部署を一緒に特定し、稼働日までの残りの期間でフォローする方法と体制を決めている |
| 操作習熟 | 病院 | 現場の職員が、操作に迷ったときにマニュアル・教材を自分で調べて解決している |
| データ移行 | — | — |
| ハードウェア・ネットワーク | 病院 | 病院側が、周辺機器を含めて全部署の配備を終えており、稼働日に向けて配備を待つものがない |
| システム連携 | 双方 | 病院とヘンリーが、連携すると決めたすべてのシステムとの連携をリハーサルの中で確かめており、暫定運用で稼働する連携がない |
| 契約・事務 | — | — |
| 推進体制 | — | — |
| 会議体の準備 | 病院 | 病院側が、リハーサルの当日の進行と振り返りを仕切り、ヘンリーは必要時の補足に回っている |
