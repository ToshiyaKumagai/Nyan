# マイルストーン DB を読む・書く（ツール層）

## 場所

プロジェクトページの `<database inline="true">` のうちタイトルが「マイルストーン進捗（のビュー）」のもの。`notion-fetch` で開き、`collection://…` の URL とスキーマを毎回取る（ハードコードしない）。

## スキーマ（2026-09-24 改修後）

| プロパティ | 型 | 書き方 |
| --- | --- | --- |
| マイルストーン | タイトル | 案件の現行の呼称。**変えない** |
| 標準の節目 | テキスト | 標準の指し方。カードを引くキー。空なら「未対応」と返し、推測で埋めない |
| 順序 | 数値 | 変えない |
| 予定時期 | 日付（範囲可） | プロセスが明示したときだけ |
| Status | セレクト | 未着手／準備中／進行中／完了／対象外 |
| 評価 | セレクト | 🔴 要介入／🟡 要観察／🟢 経過観察 |
| 現状の要約・ギャップの要約・打ち手の要約 | テキスト | 1〜2文。本文の要約 |
| 事実確認 | セレクト | あり／なし |
| 最終更新 | 日付 | 書いた日 |
| 最終更新の根拠 | テキスト | 読んだ入力の一覧 |
| 標準の版 | テキスト | 写した donyu-standard のコミット（`flow-donyu/references/VERSION`） |

## 本文の節と扱い

受け入れ条件・理想状態の本文はページに写さない（標準は `flow-donyu` が持つ）。ページの先頭の引用行にカードのパスだけを置く。

| 節 | 扱い | 誰が書く |
| --- | --- | --- |
| 現状／ギャップと打ち手／事実確認をお願いしたいこと／タスク | **最新の断面に置き換え** | nyan |
| 7領域に当てはめられなかった事実／レビュー／更新履歴 | **追記のみ** | nyan（レビューは人も書く） |

## 読む

- 一覧：`notion-query-data-sources`（SQL）で全行
- 本文：`notion-fetch`。コメント：`notion-get-comments`（`include_discussions` を立てて fetch）

## 書く

1. **書く前に読む。** 現在のプロパティと本文を取る。前回 nyan が書いた値と違えば、人の変更として「レビュー」節に記録し、その値を起点にする
2. **置き換え。** `notion-update-page` の `update_content` で、対象の節（見出しから次の `#` 見出しの直前まで）を `old_str` → `new_str` で差し替える。他の節に触れない
3. **追記。** 追記のみの節の末尾に `insert_content`（位置は当該節の最後の行の直後）。既存の行は変えない
4. **プロパティ。** `update_properties`
5. **読み戻す。** `notion-fetch` で、置き換えた節が1つだけ・追記の節が増えているだけ・他の節が無傷であることを確かめる。崩れていたら報告して止まる（重ねて書かない）

## しないこと

- 行（ページ）を消す／タイトルと順序を変える／追記のみの節を書き換える
- 「標準の節目」が空の行を推測で埋める／18行に足りない行を勝手に作る（提案を返す）
